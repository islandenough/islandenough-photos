# islandenough-photos

아일랜드이너프 인스타그램 카드뉴스 자동 업로드용 저장소입니다.

## 사장님이 하실 일
`ai-photos/` 폴더에 ChatGPT로 만든 AI 사진을 올려 주세요.

- **Add file → Upload files** → 사진을 끌어다 놓기 → **Commit changes**
- 파일 이름은 **지점 이름으로 시작**해 주세요: `양재_생일.png`, `도산_브라이덜.jpg`, `역삼_송년회.png`, `수유_가족.png`, `강남_파티.png`
- 이름에 장면(생일, 브라이덜, 송년, 크리스마스, 워크샵, 동창, 가족)을 넣으면 그날 주제에 맞는 사진이 우선 쓰입니다.
- AI 사진이 없는 지점은 홈페이지의 파티 사진이 자동으로 쓰입니다.

## 폴더 구성
| 폴더 | 내용 |
|---|---|
| `ai-photos/` | 사장님이 올리는 AI 사진 |
| `cards/날짜/` | 매일 자동으로 만들어지는 카드뉴스 7장과 게시글 (인스타그램이 여기서 사진을 가져갑니다) |
| `tools/` | 카드뉴스 제작 · 업로드 프로그램과 글꼴 (건드리지 않으셔도 됩니다) |
